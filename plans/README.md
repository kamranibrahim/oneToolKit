  smallest verification first (001), then home UX (002), then native share-in (003).

  — 003 touches Android/iOS project files and is easier to review alone.

## Findings considered and rejected

- **More catalog tools** (Morse, MIME tables, HTTP status extras): 85 tools
  already exist; catalog breadth does not create repeat opens.
- **History payload restore for every PDF tool**: deferred. 002 surfaces the last
  job and notepad; full file-path restore is a later plan (privacy + schema).
- **Streaks / tip-of-the-day / gamification**: fake habit for a utility app.
- **Cloud sync / desktop / accounts / IAP**: explicitly deferred in README;
  conflicts with “private by default.”
- **Notifications for Days Until / timer**: valuable, but not in this batch.
  Do not add `flutter_local_notifications` in these plans.
- **Image watermark, duplicate-delete, EXIF strip**: quality gaps, not habit
  loops. Separate later plans.
